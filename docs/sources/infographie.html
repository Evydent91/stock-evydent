L’application repose sur quatre outils, chacun avec un rôle précis. Trois seulement servent au quotidien (GitHub, Netlify, Supabase) ; Claude intervient uniquement pour fabriquer et faire évoluer l’application. Tous sont aujourd’hui utilisés en offre gratuite.

1Les quatre briques

L’atelier

Claude

Assistant d’intelligence artificielle qui écrit et modifie l’application à la demande de la référente.

  • Construit les écrans et les règles (stock, commandes, inventaires…)
  • Prépare les mises à jour de la base de données
  • Teste avant de livrer, explique chaque changement
N’a pas besoin d’être ouvert pour que l’équipe utilise l’appli.
Le classeur

GitHub

Range le programme de l’application et garde l’historique de chaque modification (qui, quand, quoi).

  • Deux versions : dev = version de test, main = version réelle
  • Héberge gratuitement le site de test
  • Aucune donnée du centre, aucun mot de passe
Compte : Evydent91.
La vitrine

Netlify

Publie le site réel utilisé par l’équipe, sur ordinateur, tablette et téléphone.

  • Adresse : evystock.netlify.app
  • Ne se met à jour que depuis la version main, donc après validation
  • Installable sur l’écran d’accueil du téléphone
Ne contient que l’affichage, pas les données.
Le coffre

Supabase

La base de données : articles, fournisseurs, stock, mouvements, commandes, inventaires et comptes.

  • Connexion personnelle (identifiant + code ou mot de passe)
  • Droits selon le rôle, contrôlés par la base elle-même
  • Deux bases séparées : Dev (essais) et Prod (réelle)
Les vraies données ne sont jamais dans GitHub.

4Ce qui se passe quand une assistante fait une sortie

1Elle ouvre evystock.netlify.app (ou l’icône sur son téléphone) : Netlify envoie l’affichage de l’application. 2Elle se connecte avec son identifiant et son code à 6 chiffres : Supabase vérifie qui elle est et ce qu’elle a le droit de faire. 3Elle choisit les articles et valide : Supabase retire les quantités de la réserve, les ajoute au cabinet et enregistre le mouvement à son nom. 4La référente et la responsable voient immédiatement le stock à jour, les alertes et l’historique, depuis n’importe quel appareil.

5Qui peut faire quoi

Assistantes

Sorties, retours en réserve et inventaire des cabinets ; leur propre historique. Un cabinet par défaut ; un autre cabinet est possible en remplacement, marqué « hors cabinet ».

Référente

Tout l’outil : commandes et réceptions, articles, fournisseurs, inventaire de la réserve, équipe (comptes, codes), sauvegardes. Valide chaque évolution.

Responsable

Les mêmes droits que la référente. Suit le stock, les commandes et le journal des versions ; peut créer et désactiver des comptes.

Sécurité des données

  • Un compte personnel par personne, désactivable à tout moment ; l’historique est conservé.
  • Chaque mouvement est enregistré avec le nom de son auteur.
  • Les règles d’accès sont appliquées par la base elle-même, pas seulement par l’écran.
  • La clé qui permet de créer des comptes reste chez Supabase, jamais dans le navigateur.
  • Le programme sur GitHub ne contient ni données du centre, ni mot de passe.

Sauvegardes et continuité

  • Sauvegarde complète en un clic (fichier Excel) dans l’onglet Plus.
  • Rappel sur l’accueil si la dernière date de plus d’un mois.
  • Fichier à ranger dans un dossier sûr du centre.
  • Import par Excel pour corriger les fiches articles en masse et pour l’inventaire de la réserve.
  • L’ancienne application reste consultable pour l’historique d’avant la bascule.
